# Kai Wissler portfolio

A static, single-page portfolio built with semantic HTML, CSS, and a small amount of JavaScript. Vite provides the local development server and production build without adding a client-side framework.

## Development

```bash
npm install
npm run dev
```

Vite serves the root `index.html` and updates the browser as HTML, CSS, and JavaScript change.

## Production build

```bash
npm run build
npm run preview
```

The optimized static site is written to `dist/`.
